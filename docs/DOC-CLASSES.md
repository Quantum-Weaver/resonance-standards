# Document Classes — what may be copied, what must never be

*Ratified into the standards at KP's commission, 2026-07-17 (Shuttle Run 07,
the standards overview). Origin: the question "should an agent exist that
syncs standards docs to repos that are using them?" The answer is yes — but
only for one of three classes, and naming the classes is the standard.*

## The three classes

| Class | Behavior | Examples | May an agent write it? |
|---|---|---|---|
| **REFERENCE** | Never copied. Repos *link* to the single truth. | GIT-HYGIENE, THE-HANDS, Council docs, this file | No — nothing to sync. "Defined once, referenced everywhere." |
| **SEED** | Copied once into a repo, then **diverges on purpose** — it becomes the repo's own. | `.gitignore-template`, CLAUDE-TEMPLATE, CHECKLIST-TEMPLATE | **Never.** A seed is a planting, not a mirror; overwriting one destroys repo-specific truth. |
| **MIRROR** | Verbatim copy kept in a repo for practical/runtime reasons, refreshed from a single editable truth. | the cosmic token files in consuming apps | Yes — this is the *only* class an agent maintains. |

## The separation law

Repo-specific content and agent-maintained content are separated **by file,
never by interleaving**. An agent-maintained file carries the mirror header
(below) and contains *nothing* repo-specific; repo-specific files *reference*
mirrored ones. Only where inline mixing is truly unavoidable may marked
blocks (`<!-- STANDARDS:BEGIN -->` … `<!-- STANDARDS:END -->`) be used, and
the agent may touch nothing outside its markers.

## The mirror header law (ratified pattern: cosmic's `MIRROR.md`)

Every MIRROR-class artifact declares itself at the top: **⚠ do not edit here
— the source of truth lives at `<path>`**, plus the refresh mechanism and the
date of last distribution. A mirror that cannot name its truth is not a
mirror; it is drift waiting to be discovered.

## Self-maps are generated, not hand-kept

A repo's `structure.md` (tree + manifest) is MIRROR-class where the "truth"
is the repository tree itself: regenerated by tooling, never trusted to
memory. Hand-maintained manifests lag reality — measured in this very repo,
2026-07-17 (two files missing from its own map).

## The distribution agent (scope and safeguards)

Distribution is **ziggy's craft**: the pattern proven by
`resonance-ziggy/modules/cosmic/distribute.ts` extends to standards mirrors;
new distribution work lands as ziggy modules, not as new inventions.
Safeguards, non-negotiable: dry-run first with a shown diff · agent commits
attributed honestly as agent commits · KP signs early batches until trust is
measured, not assumed · **lose-nothing** — an agent refreshes mirrors; it
never deletes or rewrites a repo's own files.
